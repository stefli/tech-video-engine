# 小红书爆款大字报封面排版体系 (Xiaohongshu Editorial Poster Standard)

## 核心设计法则（实景底图 + 实心背景色块 + 绝对零遮挡）

1. **全模块“实心高亮背景色块垫字”（Dedicated Color Plates）**：
   - 核心冲突行必须垫在**鲜艳的荧光明黄底色块（#ffe500）**上，文字为纯黑特粗体（小红书最经典视觉锤）；
   - 核心观点行垫在**烈焰红底色块（#ff2442）**上，白字特粗；
   - 叙事与数据分别垫在深邃藏青（#0f172a）与红黑（#1c080d）色块上，每一行字都有坚实的视觉衬底，绝不与复杂背景混淆。

2. **绝对零遮挡架构（Zero Occlusion Guarantee）**：
   - 严禁使用浮动在文字上方的绝对定位多边形或印章；
   - 采用自适应弹性文档流（Vertical Flex Flow），各色块之间保留 28px - 32px 的充裕安全外边距；
   - 行高 `line-height: 1.05 - 1.15`，各层微倾斜控制在 `-1.5°` 到 `+1°`，保证倾斜色块之间互不侵占，字迹 100% 清晰可见。

3. **真实机房摄影背景（Real Photo Atmosphere）**：
   - 选用真实带光斑和景深的服务器机房摄影作为暗部衬底，带有电影级晕影（Vignette），彻底告别单调纯黑或死板代码渐变。
1. **黄金比例**：以 **3:4（2160 × 2880）** 作为视觉设计基准，居中兼容 9:16 全屏（上下留白 480px）与 1:1 主页缩略图。
2. **小红书经典“荧光马克笔底色块”（Marker Highlight Box）**：
   - 第一行：主语（纯白超粗体，`150px`）；
   - 第二行：**核心动词/冲突（实心荧光黄底黑字！微倾斜 -1deg，大字报精髓所在，字号 `175px`）**；
   - 第三行：核心观点结论（高光青蓝/烈焰红反差色，`160px`）。
3. **情绪与事实爆点胶囊群（Badges Cluster）**：
   - 带有 Emoji（如 ⚡, 🛡️, ⚠️, 💥）的圆角半透明胶囊标签；
   - 包含高对比度数字（`4.8 万次/秒`，`99.4%`），3 秒内完成信息扫视传达。
4. **数据暴击横向大卡（Stats Shock Card）**：
   - 摆脱呆板的小边框，采用整体深色微光衬底，红黄两极大字并列（如 `72h➔3.2s` 巨大红字与 `24/7 自愈` 巨大黄字）。
5. **绝对禁用套路**：
   - 严禁使用任何 `border-left` 装饰竖条；
   - 严禁使用任何 `border-top` 彩色细线；
   - 严禁使用满屏黑客代码雨导致看不清中文大标题。
