# OPENCODE 24H AI ATTACK // RESIDENT AGENT SECURITY DOSSIER

## Overview
A production-grade, authoritative 4K vertical cybersecurity perspective video (`2160 × 3840`, 30fps, 54.0s) analyzing the autonomous 24/7 offensive assault against OpenCode infrastructure, and demonstrating why modern code defense requires resident autonomous agents.

## Core Production Highlights

### 1. Zero-Disk In-Engine Cyber Viewport
- Replaced heavy disk-written video clips with pure in-engine CSS/Canvas/SVG telemetry streams.
- Real-time display of eBPF kernel taint tracking, sandbox crash isolation, and live Git hot-patch compilation.
- Zero disk fragment writes; infinite vector sharpness at 4K resolution.

### 2. Mandatory 4K Anti-Compression Standard
- Rendered with `--resolution portrait-4k`, supersampling via `deviceScaleFactor=2` onto a 1080×1920 DOM canvas.
- Prevents WeChat Channels, Douyin, TikTok, and Bilibili from crushing fine terminal typography, code traces, and vector telemetry lines.

### 3. Platform Safe-Zone Compliance
- **Top Safe Zone (0 - 220px)**: Clear of text/controls.
- **Bottom Safe Zone (1360 - 1920px, 560px Clearance)**: Clear of all typography, timestamps, progress bars, and metadata to avoid overlap with platform handles, captions, like/comment sidebars, and audio discs.
- **Core Golden Focus (220px - 1360px)**: Concentrates the 104px bold headline, 16:9 native inspector viewport, 42px narrative body, and 26px/56px dual telemetry cards.

### 4. High-Velocity Acoustic Engineering
- Parallel TTS Generation: 7 broadcast voiceover chunks dispatched concurrently via `asyncio.gather` in 5.0 seconds.
- Announcer: `zh-CN-YunyangNeural` (`rate="+14%", pitch="-1Hz"`).
- Studio Mastering: 80Hz highpass, 220Hz warmth, 3.3kHz articulation boost, 8.5kHz air, optical compression, and EBU R128 loudness normalization (-21.5 dB mean, -3.0 dB peak).
- Music: 54-second procedural pulse synthesizer score with transitional whoosh effects on cut points.
